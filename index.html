    背景 · 本地图片

    支持 jpg/png/webp，建议 ≤ 4MB；恢复默认背景请用「数据管理 → 恢复默认」

    磁贴

    拖动磁贴即可排序（无需进入编辑）。要增删改磁贴，在页面空白处右键 →「编辑当前主页 / 编辑当前分组」进入编辑模式：点击磁贴修改、右上角 ✕ 删除；右键磁贴可打开快捷菜单

    网站图标

    不授权时只能猜网站的 /favicon.ico，DeepSeek、豆包等站点会拿不到图标。授权后由后台读取网页里声明的图标地址，图标更准确；拒绝则回退为首字母色块。

    分组

      点击分组名可编辑名称 / 图标；拖动左侧图标或主页卡片可排序；删除分组会同时删除组内磁贴

      每页布局

      放不下的磁贴自动进入下一页，磁贴下方可翻页

      搜索引擎

        拖动列表可调整顺序，第一位为默认搜索引擎；URL 用 {q} 表示搜索词。点「编辑」可改内置引擎的名称与网址（不会改动 MyTab 自带的默认值），点「删除」可移除不用的条目。

        数据管理

        导出为一个 ZIP 压缩包：里面是配置文件（分组、磁贴、搜索引擎、外观设置）和你的背景图片。导入时选同样的压缩包即可；也兼容旧版导出的单个 JSON 文件。导入会覆盖当前的全部配置，建议先导出一份备份。「恢复默认」会把外观、分组、磁贴、搜索引擎全部还原为出厂值，无法撤销。
